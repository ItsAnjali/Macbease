About the Project
This is a React Native app that displays a leaderboard of university clubs based on their scores. It showcases the top 3 clubs in a podium layout (Gold, Silver, Bronze) and provides additional details about club achievements and updates.

Features:
Top 3 Clubs Podium: Displays the top 3 clubs in Gold, Silver, and Bronze.

Club Cards: Shows the remaining clubs with their scores and images.

Club Achievements & Updates: Lists club achievements and upcoming events.

Join Club Button: Placeholder button to "Join a Club".

How It Works:
Data: Clubs are sorted by score and displayed in a leaderboard.

Podium & Cards: Top 3 clubs use a unique podium design, and the rest are displayed in card format.

Dynamic Styling: getRankColor() function applies different colors based on the club’s rank.
